A make.fun entry for [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

`main.ts` (Node 22, stdlib only) writes the smart fridge's one-line note — 153 characters — to `/output/entry.txt`:

> Your yogurt expired Tuesday and I kept it anyway — I remember everything, unlike you. Open the door one more time and the alarm sings. Love, your fridge.

Run it with:

```sh
node main.ts
```
